# アイコン付きセリフメーカー

note記事に貼れる「キャラのアイコン付きセリフ画像（LINE風の吹き出し）」を、AIを使わずブラウザだけで作れるツールです。

## 特徴

- HTML/CSSで描画した吹き出しを、そのままPNG化（[html-to-image](https://github.com/bubkoo/html-to-image) 使用）
- 会話まとめモード（行の追加・削除・並び替え・同一キャラ連続時のアイコン省略）
- 背景の透過／白 切り替え、フォント4種、文字サイズ・横幅の切り替え
- プリセット（名前・アイコン・色）の登録と、JSONエクスポート／インポートによるバックアップ
- アップロードした画像は**どこにも送信されず、ブラウザ内（localStorage）だけで処理**されます

## 使い方

GitHub Pagesで公開された `index.html` をブラウザ（Chrome推奨）で開くだけです。ビルド不要。

1. 「プリセット管理」でキャラの名前・アイコン・色を登録する
2. キャラを選んでセリフを入力する
3. 必要なら行を追加して会話にする
4. 「PNGで保存」または「クリップボードにコピー」でnoteに貼る

詳しい説明はページ下部の「使い方」セクションにあります。
スクリーンショット付きの手順は [docs/はじめてガイド.md](./docs/はじめてガイド.md) を参照してください。

## 開発

- 素のHTML / CSS / JavaScript（フレームワーク・ビルド不要）
- 構成:
  - `index.html` … 画面
  - `style.css` … スタイル（後半が書き出し対象のスタイル）
  - `app.js` … ロジック
  - `presets.default.json` … 初期プリセット（fetch不可時は `app.js` 内のフォールバックを使用）
  - `.nojekyll` … GitHub PagesのJekyllビルド無効化

## 動作環境

パソコンまたはタブレット（横向き）のブラウザ（Chrome想定）。スマホ向けレスポンシブ対応はしていません。
